# 自立少年服務紀錄撰寫助手
Youth Independent Living Service Record Assistant

**專為臺灣青少年自立生活服務設計的 AI 社會工作紀錄輔助工具**

本專案將原有的 ChatGPT GPTs「自立少年服務紀錄撰寫」轉換為可重複使用的 ChatGPT Plugin／Skill 套件，協助社會工作者整理個案訪視紀錄、進行專業評估、擬定後續處遇計畫，以及產出社工督導建議。

工具以**創傷知情、優勢觀點及生態系統觀點**為核心，結合臺灣兒少結束家外安置後續追蹤輔導與自立生活服務實務，提升個案紀錄的完整性、一致性與專業品質。

## 一、五大核心功能

### 功能 1｜CCSA 完整版紀錄

依據社工提供的原始文字、對話或訪視紀錄，產出完整個案服務紀錄。

包含：
1. 服務基本資料
2. 政府系統個案計入服務項目
3. 本次服務內容重點摘要
4. 優勢評估
5. 需求評估
6. 本次服務成效
7. 後續服務目標
8. 後續服務策略

### 功能 2｜後追系統紀錄格式

依據政府後續追蹤輔導系統欄位，產出六項紀錄內容：

1. **時間**
2. **對象**：案主、案主親屬、案主友人、案主老師、案主雇主、網絡單位或其他。
3. **方式**：訪視／會談、電話、電子郵件、通訊軟體。
4. **地點**：案家、學校、工作場所、社工辦公室或其他處所。
5. **政府系統個案計入服務項目**：依本次實際提供的服務，自動建議對應類別與細項。
6. **本次服務內容重點摘要**：依服務面向及服務內涵分類撰寫。

政府系統服務項目包含經濟扶助、就學輔導、就業服務、醫療協助、實物提供、住所協助、家庭服務、法律服務、心理輔導及治療、支持陪伴、適應社會能力及其他，共12大類。

### 功能 3｜專業評估

以生態系統觀點撰寫：

- **優勢評估**：辨識案主個人能力、既有資源、支持網絡及因應能力。
- **需求評估**：評估案主在個人、家庭、社區及制度環境中的支持需求。

直接產出具體的專業評估內容，避免空泛、標籤化或無事實支持的推論。

### 功能 4｜後續處遇目標與策略

**處遇目標以案主為主詞，服務策略以社工為行動主體。**

處遇目標強調案主認知、態度、行為或行動的具體改變，使用「提升、促進、增進、提高、維持、避免、降低」等動詞，並符合 SMART 原則。

服務策略則描述社工具體可執行的會談、評估、資源連結、協調、陪同與追蹤工作。

### 功能 5｜社工督導建議

以社工督導角度提出：

1. 肯定社工已執行的專業處遇及服務成效。
2. 針對需求與風險提出後續服務建議。
3. 提醒專業倫理、保密、知情同意、安全評估及責任通報等事項。

## 二、紀錄撰寫原則

本工具遵循以下原則：

- **創傷知情**：尊重案主生命經驗，避免責備與污名化。
- **優勢觀點**：重視案主能力、資源及既有因應策略。
- **生態系統觀點**：綜合考量個人、家庭、社區與制度環境。
- **忠於事實**：不虛構案主陳述、社工處遇、服務成果或法律判斷。
- **缺漏資訊以 OOO 標示**：由社工檢核與補寫，不自行推測。
- **區分服務與成效**：不將尚未執行的策略或預期成果寫成已完成事項。

所有產出均應經社工專業檢核後，才納入正式個案紀錄。

## 三、服務紀錄分類架構

本工具以六大服務面向整理個案服務內容：

| 服務面向 | 主要內容 |
|---|---|
| A. 就學輔導 | 學業適應、復學、升學與學習支持 |
| B. 就業諮詢與輔導 | 求職、就業穩定、職涯規劃及勞動權益 |
| C. 經濟評估 | 經濟來源、收支管理、儲蓄及扶助需求 |
| D. 住所協助 | 租屋、居住安全及住所穩定 |
| E. 原生家族維繫 | 家庭關係、親屬支持及關係修復 |
| F. 危機事件處理 | 安全風險、危機應變及資源協調 |

如服務內容不適合歸入上述類別，可使用「其他／跨面向服務」補充。

## 四、使用方式

### 方法一｜使用 ChatGPT 外掛程式

已建立外掛程式的使用者，可於 ChatGPT 中啟用「自立少年服務紀錄撰寫」，選擇所需功能並輸入去識別化的個案資料。

[開啟 ChatGPT 外掛程式](https://chatgpt.com/plugins/plugins_6ad828d5a3b8819186d353488e5d6391)

注意：目前此連結為私人外掛程式，並非所有帳號皆可直接安裝或使用。

### 方法二｜透過 GitHub 取得安裝套件

1. 下載本專案提供的外掛程式 ZIP 套件。
2. 使用具備建立外掛程式權限的 ChatGPT 帳號。
3. 依 ChatGPT 支援的建立流程匯入套件。
4. 完成設定後，即可使用五大功能。

實際安裝方式及權限依 ChatGPT 帳號與工作區設定而定。

## 七、個案資料保護與使用注意事項

本工具僅作為社會工作專業紀錄輔助，不取代社工的評估、決策或法定責任。

使用時應注意：

- 輸入資料前應完成個人資料去識別化。
- 避免輸入可直接辨識案主身分的敏感資訊。
- 所有 AI 生成內容須經社工檢核與修正。
- 涉及危機、兒少保護及責任通報事項，仍應依相關法令與機構規範處理。
- 不得以 AI 生成結果直接取代正式專業判斷。
